# Harlem Renaissance

https://github.com/Mjfam07/Marcus_Smith.git

Features

Player Movement

Players can move left and right using the keyboard and jump using the spacebar. Movement will be programmed using keyboard inputs and conditional statements.

Platforms and Gravity

The player can jump onto platforms and fall due to gravity. I will use Pygame's collision detection and variables to control jumping and falling.

Coin Collection

Players can collect coins throughout the level. Each collected coin will increase the player's score.

Obstacles

Players must avoid obstacles while navigating the level. Colliding with an obstacle will cause the player to restart.

Winning System

Players will win by reaching the end of the level. A victory message will appear when the player reaches the finish line.

Character Animation

The character will have simple animations for walking and jumping using different images or sprites.

Challenges

Learning how to implement gravity and jumping physics in Pygame.

Understanding collision detection between the player, platforms, and obstacles.

Learning how to animate characters using sprites.

Organizing the game using functions and classes.

Outcomes

Ideal Outcome:

My ideal outcome is to create a complete 2D platforming game with multiple levels, character animations, collectible coins, obstacles, sound effects, and a scoring system. I want the game to be visually appealing, interactive, and enjoyable to play.

Minimal Viable Outcome:

The minimum outcome is a working game where the player can move left and right, jump between platforms, and reach a finish line. Even without advanced animations or multiple levels, the game should demonstrate basic platforming mechanics.
